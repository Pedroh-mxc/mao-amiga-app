# App Instituto Mão Amiga

App em React Native (Expo) para registrar e consultar doações.

## Roteiro de demonstração (até 3 min)
1. Registrar uma doação (ex.: Roupa, 5, Ponto Central)
2. Abrir "Minhas doações" e ver o histórico e o resumo por tipo
3. Filtrar digitando "rou" na busca
4. Abrir uma doação, tocar em Editar, mudar a quantidade e salvar
5. Abrir outra doação e Excluir (mostrar o Cancelar e depois confirmar)
6. Fechar o app de verdade, reabrir e mostrar que os dados continuam
